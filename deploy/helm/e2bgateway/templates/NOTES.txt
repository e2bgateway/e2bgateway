⚠️  Prerequisites (agent-sandbox backend)
-------------------------------------------------------------

The agent-sandbox backend is in-cluster only and requires
agent-sandbox v1.0.11 components installed in this cluster:

  • CRDs: sandboxes.agents.x-k8s.io and
    sandboxclaims/sandboxtemplates/sandboxwarmpools.extensions.agents.x-k8s.io
  • Controller: registry.k8s.io/agent-sandbox/agent-sandbox-controller:v1.0.11
  • Router (needed for cold-start CreateSandbox with envs):
    registry.k8s.io/agent-sandbox/sandbox-router-go:v1.0.11, reachable as a
    sandbox-router-svc Service (or set config.backends[].config.gatewayName /
    gatewayNamespace / apiURL to point at yours)

See: https://github.com/kubernetes-sigs/agent-sandbox

📌 Port Forwarding
-------------------------------------------------------------

Port forwarding is available automatically on backends that support it
(agent-sandbox, opensandbox):
  • List ports: GET /sandboxes/{sandboxID}/ports
  • Get port URL: GET /sandboxes/{sandboxID}/ports/{port}

⚠️  Scaling
-------------------------------------------------------------

Keep replicaCount at 1: the envd access-token cache and sandbox->backend
routing map are per-process in-memory state. Additional replicas will fail
data-plane token validation (401) until a shared state store is available
(tracked in https://github.com/e2bgateway/e2bgateway/issues/90).
